# Support

## Where to ask

- A bug in a Spellbound package: open a Bug issue in that package's repository. The form asks for what happens, the steps, and your environment.
- A question, an idea, or help getting started: the Spellbound Studios Discord, https://discord.gg/CtWfrZQNhY.
- Documentation: each package's `Documentation~` folder, linked from its Package Manager page, and https://spell-bound-studios.gitbook.io/spellbound-docs/.

## What to include in a bug

- The Unity version and the operating system.
- The version of every Spellbound package installed, as the Package Manager shows it. Once Core ships the `core about` operation, paste its output: it prints all of this in one block.
- Whether it happens in the editor, a development build or a release build.
- The steps from a fresh start, and the relevant lines of the log.

## What to expect

We answer a bug within two working days. A fix lands on the package's `beta` branch first and reaches a released tag at the next release of that package. The version a fix carries follows semantic versioning: a fix is a patch, a new feature a minor, a break a major.
