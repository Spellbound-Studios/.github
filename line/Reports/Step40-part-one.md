## Decisions

The plan's twelve answers and the developer's one answer held as written. The rulings in the run are in "The shape of the work"; the sign-off's are the twenty-four above. Facts that changed during the step: Inventory's `main` was 7b0e66a, not the prompt's 3694271; Places registers `places.layer-owner-installed` over `PlaceDefinition`, so a checks line reads order, not adjacency; WorldObjects' play-mode suite reads 23 only with `--include_explicit true` (`CollisionPartsBudgetTests` is Explicit); `OperationContext`'s constructor is internal to Core, so an operation's testable overload takes settings and a dry-run flag; a test assembly's `IItemDefinitionSource` is installed whenever it compiles, so the real `inventory.preset-source-missing` answer is shown only with WorldObjects absent or through the internal overload; `ObjectPreset` derives from Core's `HashedScriptableObject`, so a bridge over it needs `Spellbound.Core` and D9 cannot see why; the Pipeline console buffer survives recompiles, so a literal `error CS` tail can read a red run's lines until the editor is reopened or `--since` is used; `recompile_status` answers `completed` or `up_to_date`, never `idle`; `sed -i` in Git Bash rewrites CRLF as LF.
