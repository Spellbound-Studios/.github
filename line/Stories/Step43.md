### W2b-5 GeoForge: the fraction encoding and the fill-time occupancy skip

- **Outcome:** first, `VoxelEncoding.DensityFromFraction(float solidFraction)` joins GeoForge's encoding with WorldForge's exact expression, `(sbyte)(solidFraction * byte.MaxValue + sbyte.MinValue)`, proved equal to that expression by a test over the full input range the voxelize job produces (every float from 0 to 1 by bit pattern); the voxelize job calls it for the ceiling, floor and ground bands and calls `VoxelEncoding.IsSolid` for the zero rule, so the arithmetic does not change and the hashes hold. Then the skip: `GeoChunkEngine.SetVoxels(in ChunkFillRequest, IDensitySource)` asks the source's occupancy when the source implements `IOccupancySource` and the volume's setting is on, and a chunk whose box classifies Empty or Solid and whose store holds no edits is not filled: no job is scheduled, the chunk takes a uniform state (air or rock) that the march skips as a uniform `DensityRange` does today, the residency event reports it resident, and point queries answer from the classification. A Mixed chunk fills as today, and a source without occupancy is never asked. The setting is a `VoxelVolumeConfig` field, `SkipFillByOccupancy` (default on), so every `IGeoVolume`, GeoVolume and a game's own implementation alike, gets it through the engine. A uniform rock chunk carries no material, because no surface lies inside it and a neighbour's halo comes from the neighbour's own fill. The first edit on a uniform chunk runs the real fill and then applies the edit (W2b-6).
