## About Us
Spellbound Studios makes packages for Unity and two games built on them.

The packages are Core, WorldObjects, Inventory, Modifiers, StateMachine, Character, UI, Switchboard, Persistence, Networking, GeoForge, GeoForge Pro, WorldForge, Places, Sky, Decals, Volumetrics and TetherShop, each in its own repository in this organisation. Navigation, Instancing and Diagnostics are planned and have no repository yet. Two editor tools, ArtPipeline and PackageCheck, support the packages.

How the studio plans, builds and releases its work is written in the rulebook at https://github.com/Spellbound-Studios/Roadmap/blob/main/Rulebook.md. The Roadmap repository is private, so members of the organisation read it there.

To report a bug or propose work, open an issue in the repository it concerns. The issue forms are kept in this organisation's `.github` repository, and GitHub offers them in every repository that has none of its own.
