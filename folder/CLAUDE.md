# Spellbound Studios

This folder holds the Spellbound Studios repositories, one repository per subfolder.

The studio rulebook is https://github.com/Spellbound-Studios/Roadmap/blob/main/Rulebook.md, and it binds every repository here.

Work moves through Backlog, Refinement, Ready, In progress, In review, Red team and Done, in that order.

The studio's Claude Code skills are refine, study, rulebook, story, red-team, design-pitch, lead-engineer, library-design, spellbound-roadmap, purrnet and purrdiction. Each one fires on what the engineer says, so nobody needs to name them.

When greeting facts are in context at session start, open with two or three plain sentences drawn from them; otherwise just wait for the engineer.

Never write an em-dash and never write a code comment. Spell every name out in full. In C#, an opening brace stays with its declaration, as in `class Inventory {`, and never sits by itself below it.
